# Time Served Estimator

Louisiana truth-in-sentencing time-to-serve estimator for client meetings. Clone of GitHub `hammersong44-dot/pd-sentencing-calculator` (published at https://hammersong44-dot.github.io/pd-sentencing-calculator/).

- Open `index.html` (published page) or `Time Served Estimator - offline.html` (offline copy) by double-clicking.
- Branded 2026-10-24: office dark palette (Night ground, Deep Navy header, brass accents), logo and name header, PO Box/phone footer. The calculation code was not touched.
- Dark by design (not tied to the OS setting).
- Rules shown on the page: La. R.S. 15:571.3, 15:571.3.1, 15:828, 15:541; C.Cr.P. art. 880. Verify against current law before relying on it.
